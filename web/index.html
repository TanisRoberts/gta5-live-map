From the repository folder:

powershell -ExecutionPolicy Bypass -File tools\tile-ripper\build.ps1 ^
    -Game "<your GTA V folder>"

Nothing is uploaded anywhere, and no game artwork ships with this project — the map is built from the files you already own.
